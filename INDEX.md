## 🎨 Customization Tips

### Change Colors
Edit `resources/css/app.css`:
```css
/* Update color values */
--primary: oklch(...);
--secondary: oklch(...);
```

### Update Logo
Replace in pages:
```tsx
<div className="...">⚖️</div>  // Change emoji or use image
```

### Add Real Images
Replace placeholder:
```tsx
<AnimatedImage src="/your-image.jpg" alt="Description" />
```

### Connect Data
Add API calls:
```tsx
const { data } = useQuery({ queryKey: ['dashboard'] });
```
